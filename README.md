# 🚗 Vehicle Management System

A Java console-based application developed to manage vehicle records efficiently using Object-Oriented Programming (OOP) concepts. This project allows users to add, view, search, update, and delete vehicle information through a simple menu-driven interface.

## Features

- Admin Login Authentication
- Add Vehicle Records
- View All Vehicles
- Search Vehicle by Number
- Update Vehicle Details
- Delete Vehicle Records
- Display Total Number of Vehicles

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner Class

## Java Concepts Used

- Classes and Objects
- Constructors
- Methods
- ArrayList
- Loops
- Switch Case
- Conditional Statements

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Vehicle-Management-System.git
   ```

2. Open the project in VS Code, Eclipse, or IntelliJ IDEA.

3. Compile the program:
   ```bash
   javac VehicleManagementSystem.java
   ```

4. Run the program:
   ```bash
   java VehicleManagementSystem
   ```
